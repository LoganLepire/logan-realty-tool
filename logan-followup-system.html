    How it works: This tool creates Gmail drafts — not sends. You always review before anything goes out. No emails leave without your eyes on them first.

    Connect Gmail Account

    To enable automatic Gmail draft creation, this tool uses the Gmail API via Google OAuth. Here's how to set it up in a few minutes:

    1. Go to console.cloud.google.com and create a free project
    2. Enable the Gmail API
    3. Create OAuth 2.0 credentials (Desktop App type)
    4. Paste your Client ID below

    Not technical? No problem — the tool still works perfectly without Gmail integration. Just use the "Copy Email" buttons and paste into Gmail manually.
